# 全景选股系统

> 最后更新: 2026-05-07 | 数据底座: prices_full.pkl (5739只 × 2019-2026全量)

系统由三条腿组成，按 CSI300 MA60 自动切换：

```
               CSI300 MA60 开关
              ┌───────┴───────┐
         MA60以下          MA60以上
              │                  │
     ┌────────▼──────┐  ┌───────▼────────┐
     │ 腿1: 暴跌抄底  │  │ 腿3: 黄金坑     │
     │ (v5.2选股)    │  │ (牛回头上车)    │
     │ 逆势均值回归   │  │ 顺势趋势跟踪    │
     └───────────────┘  └────────────────┘
              │                  │
              └────────┬─────────┘
                       │
              ┌────────▼────────┐
              │ 腿2: 北向择时    │
              │ 宏观仓位调节     │
              │ 外资动向→仓位    │
              └─────────────────┘
```

## 腿1: v5.2 暴跌抄底 (熊市)

**逻辑**: 恐慌中买，别人恐惧我贪婪

**入场**:
- 26大师投票 → 4-7票 = ★★★★（>7票=拥挤共识，反而不灵）
- 60日暴跌 >20%
- 缩量 <0.8x（机构惜售）
- 不独跌：超额跌幅 <15%（不是板块集体崩）

**排名**: score = (0.8 - 量比)×2 + abs(跌幅)×1.5

**仓位**: TOP4，月度调仓，同行业 ≤2只

**出场**: 20天底仓 → RSI>70 + 放量>1.5x（聪明钱出货）→ 否则60天到期

**环境**: CSI300 < MA60 → 仓位减到2只

**回测**: 全池1903只×84月，胜率58%，均+6.39%，年均15笔

**文件**: `src/signals/daily_generator.py`, `src/masters/__init__.py`

## 腿2: 北向择时 (全周期仓位调节)

**逻辑**: 外资是最聪明的钱，跟着走

**规则**:
- 北向5日净流入 > 2年P90 → 满仓（100%）
- 北向5日净流入 > 2年P70 → 半仓（50%）
- 北向5日净流入 < 0 → 空仓（防御）
- 南向回流加成：内地钱回流A股 → +1档

**标的**: 不选股，纯 CSI300 ETF

**回测**: 2020-2026 +37.3%，夏普0.65，在场仅16%

**文件**: `src/surge/north_gate.py`

## 腿3: 黄金坑 (牛市趋势回调) [待开发]

**逻辑**: 趋势股回调 = 牛回头上车

**数据验证** (8只趋势股 × 762次回调):

| 回调深度 | 创新高率 | 判读 |
|----------|---------|------|
| -5%~-10% | 92% | ⭐ 最佳上车 |
| -10%~-15% | 80% | ✅ 可用 |
| -15%~-20% | 57% | ⚠️ 悬崖 |
| >-20% | 36% | ✗ 反转 |

**三条铁律**:
1. -15%是分水岭
2. 缩量(<0.8x)回调 = 最强信号
3. 放量回调反弹不慢（洗盘），但深回调放量 = 真跑路

**个股王者**: 沪电(+1400%, -3%~-15%全100%创新高), 西部材料(+1291%)

**待解决问题**:

3. 出场规则（复用RSI+放量？）
4. 仓位管理与v5.2协调
5. 全池回测验证

## 共享设施

**数据管道**:
- 价格: `prices_full.pkl` (5739只 × 1778天，2019-01-02~2026-05-07)
- 基本面: `fundamentals_daily.pkl` + `financials.pkl`
- 北向: `macro_north_flow.pkl`
- 更新: `update_today.py` (每天16:00，按天批量拉取)
- 选股: `daily_generator.py` (每天16:01，纯缓存命中)

**质量闸门** (8道，共享):
ST、壳公司(PB>10且亏损)、市值<30亿、日成交<3000万、僵尸股、换手异常、极缩量<0.5x、阴跌(连跌10天)

**出场引擎** (`position_manager.py`):
移动止损线、RSI顶部信号、闸门关闭强制出场

## 开发铁律

1. 阈值先查数据分布再定，禁止拍脑袋

4. 主动提盲区和风险
5. 重要结论备份到 `quant_archive/`
6. 方向 → 假设 → 数据验证 → 确认 → 代码
