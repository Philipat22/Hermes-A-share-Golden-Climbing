# 冯柳"弱者体系"认知引擎 v1

## 背景

冯柳，网名"茅台03"，2003年入市，9年约370倍收益。2014年加入高毅资产任基金经理，管理百亿规模。他是A股极其罕见的"散户出身→百亿基金经理"的案例，其框架完全是A股原生、实战验证的。

> "弱者体系就是假定自己在信息获取、理解深度、时间精力、情绪控制、人脉资源等方面都处于这个市场的最差水平，能依靠的只有时间、赔率与常识。"

## 一、核心心智模型

### 1. 弱者体系（元假设）

**原著引用：**
> "我把市场分为看得见的和看不见的两种，强者是要深度研究，让盲区消失，所有方面都要看见，弱者是只要不呈现就看不见。"

**核心逻辑：**
- 你永远不可能比机构知道得多——所以别去研究"别人不知道的事"
- 赚的不是"我比别人聪明"的钱，是"市场已经充分反映了悲观，但悲观可能是过度的"的钱
- 要求信息必须"简单直白地呈现"，不是"我挖掘研究后的理解"

**对策略开发的影响：**
- 不需要深度基本面研究（研报都比你专业）
- 需要的是：识别市场已经把坏消息消化到什么程度
- DD≥30%这个信号本身就是"负面已经充分呈现"——这是冯柳框架会认可的逻辑起点

---

### 2. 赔率优先于概率

**原著引用：**
> "我一向把赔率放在概率前面来思考，所以会分散买很多个股票来跟踪，只有发现两者统一的时候才会重点集中。"

**核心逻辑：**

| | 概率思维 | 赔率思维（冯柳） |
|---|---|---|
| 先考虑 | 这个有多大概率赚钱？ | 赚了能赚多少？亏了会亏多少？ |
| 入场 | 确定性高时集中 | 赔率高时分散，确定性出现后集中 |
| 典型行为 | 等确定性→重仓 | 散买→跟→确认→集中 |

**黄金坑策略的对齐：**
- DD≥30% = 下行空间有限（跌了很多了），上行空间未知（反弹弹性不确定）→ 赔率结构
- 但缺少冯柳的"信号→分散跟→确认后集中"这个渐进过程

---

### 3. 三种下跌：杀估值、杀业绩、杀逻辑

**原著引用：**
> "杀估值的最好，因为跌下来后导致其下跌的因素就解除了；杀业绩的其次，但只要针对经营节奏和变化进行投资也是很好的机会；最要小心的就是杀逻辑的，这个一般不建议参与，很难抄对。"

**A股适配规则：**

```
判断这是什么性质的下跌：

1. 杀估值（买入！）
   特征：公司基本面没问题，纯市场下跌/板块拖累
   信号：PE从历史中位跌到低分位，但营收/利润还在增长
   例：2022年的白酒——商业模式没变，估值跌回了

2. 杀业绩（可以买但要注意）
   特征：公司经营节奏出问题，但行业和逻辑没问题
   信号：营收增速放缓，利润率下降，但行业渗透率还在提升
   例：周期股在周期底部——业绩差但不是逻辑死了

3. 杀逻辑（避开！）
   特征：商业模式被颠覆，或者核心竞争力丧失
   信号：行业政策根本性改变、技术替代、竞争对手降维打击
   例：教培行业2021年——不是估值问题，是逻辑死亡
```

**这是冯柳框架对黄金坑策略最大的贡献：**
不是所有DD≥30%都能买。DD≥30%只是一个入口信号。下一步必须判断——这30%是杀估值、杀业绩还是杀逻辑？

### 4. 关注度×购买度矩阵

**原著引用：**
> "首选高关注度、低购买度的，估值容易抬升；回避高关注度高购买或低卖出度的，这个估值有下行压力。关注度可以从报告以及交流热度上得知，购买度可以从图形阶段及筹码结构上得知。"

**矩阵：**

| | 低购买度 | 高购买度 |
|---|---|---|
| **高关注度** | ⭐ 最佳：估值容易抬升 | ❌ 回避：估值下行压力 |
| **低关注度** | ⚠️ 一般：估值低但提升慢 | ⚠️ 一般：变化不大 |

**A股规则化：**
- **关注度代理指标**：雪球讨论量、研报覆盖数、龙虎榜上榜频率、百度搜索热度
- **购买度代理指标**：换手率vs历史均值、股东人数变化（增加=购买度高）、机构持仓变化
- **理想标的**：大家都在讨论（高关注）但还没买（低购买）→ 买。对应AI概念：热度高但筹码还没被散户接盘
- **危险标的**：所有人都讨论且都买了 → 卖。对应：AI概念股已经被散户疯抢

### 5. 三个声音

**原著引用：**
> "投资要听三个声音：一是企业的声音，就是了解企业基本面；二是市场的声音，就是借助市场智慧完善认识；三是自己内心的声音，这是获得角度感和进程感的方式。毕竟主仓事关重大，长期持有的过程中又会碰到许多考验，极端情况下一定会放大自己内心的缺点。"

**三元认知模型：**

```
企业的声音 → 基本面是什么？
    ├─ 生意模式是否可预期、可展望、可想象？
    ├─ 现在处于什么阶段？

市场的声音 → 市场在定价什么？
    ├─ 涨的时候市场在想什么？（乐观逻辑）
    ├─ 跌的时候市场在想什么？（悲观逻辑）
    ├─ 哪个逻辑更可能被证明是错的？

自己的声音 → 我为什么在纠结？
    ├─ 开小仓感受：持仓后是踏实还是焦虑？
    ├─ 焦虑 = 认知不足以支撑仓位 → 减仓
    └─ 踏实 = 认知和仓位匹配 → 可加仓
```

**策略开发中的应用：**
这个三元模型是Hermes说的"对手方引擎"缺失的部分。我们现在只做了"市场的声音"（VR、DD），但没做"企业的声音"和"自己的声音"。

---

### 6. 低位证明无、高位证明有

**原著引用：**
> "在低位时，如果你不能证明它无那它就是有，在高位时，如果你不能证明它有，那它就是无，这是基本的赔率思考模式与事实无关。"

**核心逻辑——这是冯柳最反直觉的一条：**

| 位置 | 默认假设 | 举证责任 |
|------|---------|---------|
| 低位（跌了很多） | 它有价值 | 你必须证明它没价值才能卖 |
| 高位（涨了很多） | 它没价值 | 你必须证明它有价值才能持有 |

**大多数人的错误（冯柳原话）：**
> "而很多人却恰恰相反，在高位时花大量精力去论证它有，像赌徒一样坚定自己；在低位时却为可能的没有担忧不已，像懦夫一样被恐惧控制不敢伸手触碰机遇。"

**对黄金坑的意义：**
DD≥30%的票，你的默认立场应该是"它有价值"——除非你能证明它杀的是逻辑。不要先去"论证它为什么还能涨"——那是高位票才需要做的事。

---

### 7. 避免永久性资本损失

**原著引用：**
> "我对自己的要求是，避免永久性资本损失，但对可逆的下跌不强求回避，也就是说会被中长期因素修复的波动可以不理会。"

和Marks的风险定义惊人一致。两个不同体系的大师，在同一个问题上达成共识：**风险≠波动，风险=永久损失。**

---

### 8. 底部不定量

**原著引用：**
> "股价处在高位，要做计算题，要定量。但在市场底部，如果再去算账，就很容易吃大亏。"

| 位置 | 做什么 |
|------|--------|
| 高位 | 算账：估值多少？成长性能支撑吗？算清楚才持有 |
| 低位 | 看方向：坏的有没有被充分反映？方向对就行，别算具体底部 |

---

### 9. 趋势→预期正反馈

**原著引用：**
> "趋势是由预期决定，但预期可以由趋势强化并反过来再影响到趋势上，形成正反馈直至极限。在形成期，预期是最重要的因素，在演变强化期，趋势是最关键的方面，而转折期，则往往是双方极限值共振的结果。"

**应用到AI机会：**

AI当前处于什么阶段？
- 形成期（2023年）→ 预期驱动：GPT-4发布，市场开始想象
- 强化期（2024-2025年）→ 趋势驱动：算力业绩兑现，股价持续上涨吸引更多资金
- 转折期（？）→ 极限值共振：预期拉满+趋势减速 → 可能出现

**现在的AI在什么阶段？处于强化期——预期和趋势互相强化中。**
冯柳会说：趋势不改可以继续拿，但如果涨速开始下降（"新"消失），就该警惕。

## 二、决策树

```
一只票进入视野时，问：

Q1: 这是杀估值、杀业绩还是杀逻辑？
    ├─ 杀估值 → 最优，可以买
    ├─ 杀业绩 → 可以，但要判断节奏
    └─ 杀逻辑 → 坚决不碰

Q2: 它在关注度×购买度矩阵的哪个象限？
    ├─ 高关注+低购买 → 最优，买入
    ├─ 高关注+高购买 → 回避
    ├─ 低关注+低购买 → 可关注，但慢
    └─ 低关注+高购买 → 可持有，不太会大涨

Q3: 在低位还是高位？
    ├─ 低位 → 默认"有价值"，你只需证明它不是杀逻辑
    └─ 高位 → 默认"没价值"，你必须证明它还能涨

Q4: 三个声音分别说什么？
    ├─ 企业声音：生意模式清晰吗？可预期/可展望/可想象吗？
    ├─ 市场声音：市场现在在定价什么逻辑？乐观还是悲观？
    └─ 自己声音：持仓后感觉踏实还是焦虑？

Q5: 赔率与概率是否统一？
    ├─ 赔率高但概率低 → 小仓试探
    ├─ 赔率高且概率上升 → 加仓集中
    ├─ 概率高但赔率低 → 减仓（确定性已经price in了）
    └─ 赔率概率都不好 → 不碰
```

## 七、冯柳的灰色地带——他会犹豫的地方（第三层）

### 矛盾1：稳定vs.高回报——估值模型揭示的

**原著（《关于估值的有趣想象》2005）：**

冯柳用了一个数学模型：
> A方案：投入100元，每年50%概率赚100元，50%概率亏30元，交替出现
> B方案：投入100元，每年稳定赚18%
>
> 单年期：A期望回报35%，B是18% → A更优
> 多年期偶数年：A复利18.3%，B是18% → 几乎持平
> 多年期奇数年且开始就赚：A第一年100%，但逐年下滑
> 多年期奇数年且开始就赔：A从-30%开始上升，最大不超过18%

**冯柳的结论：**
> "绝大多数情况下，稳定比高利润更重要，如果在足够长的时间段里来看，稳定的盈利能力则比一切都重要！"

**但这个结论和他自己的操作有矛盾——**
他9年370倍靠的不是"稳定18%"，是超高弹性的逆向重仓。他的"弱者体系"在理论上追求稳定，在实践上追求高赔率。

**对策略开发的含义：**
```
高赔率策略（黄金坑）：中位+2.6%，但有单笔-12%的亏损 → A方案
低波动策略（高股息等）：稳定但低回报 → B方案

冯柳会说：你要知道你在选哪种方案。
- A方案：开始就赚的人会变得贪婪（第一年100%回报让人飘飘然）
- A方案：开始就赔的人会变得恐惧（第一年-30%就怀疑人生了）
- 只有理解了周期的长期性，才知道A方案的大赚和大赔都是正常的
```

### 矛盾2：弱者 vs. 高仓位

**冯柳说：**
> "我的投资风格是不择时、不对冲、不用杠杆、不做空，始终保持高仓位单边做多。"

**矛盾点：**
如果你承认自己是弱者（信息差、精力差），为什么还要始终保持高仓位？弱者的自然反应应该是低仓位避险。

**冯柳的解法（隐含的，他没有明说）：**
他的高仓位是通过**分散**来实现安全的。赔率优先+分散介入→即使一部分亏损，另一部分大赚，整体还是赚钱。

> "首先要满足高仓位原则，所以在概率不足的时候我会在很多赔率高的股票上做分散投资，当确定性大的时候再换仓提升比例。"

**这对黄金坑策略的含义：**
你现在的策略是相对集中的（少量票、重仓）。冯柳会问：你怎么知道这一只不是"开始就赔"的那种？

他的答案不是"更精准地选股"——是**持有更多只，让概率发挥作用。**

如果你只有3-5只票，运气成分会压倒技能。冯柳的"分散→集中"不是"先试3只然后集中到1只"，是"试很多只，让概率自然筛选出好票，再对那些加仓"。

### 矛盾3：反身性的陷阱

**原著（《反身性原理的实际应用》2005）：**
> "在市场的某个阶段、在一些周期开始的时候，那些有着不断融资需求、无止境扩张、为投资者所反感的企业中，有一部分带着反身性特点的股票，会产生出比那些优质公司更疯狂的资本利润，这是在一种极大的金融幻觉下诞生出来的、永动机般的利润。"

**翻译：**牛市里最赚钱的不是好公司，是那些"借钱→扩张→股价涨→更容易借钱→继续扩张"的反身性股票。

**这是冯柳对AI概念股最精准的判断工具：**

| 类型 | 特征 | 冯柳会说 |
|------|------|----------|
| AI反身性股票 | 融资→研发→GPU→估值提升→更容易融资 | 可以参与，但要知道这是"金融幻觉"驱动的 |
| AI真实生产力股票 | 技术壁垒+客户增长+现金流改善 | 这才是"可预期、可展望、可想象"的 |
| AI蹭概念股票 | 没有反身性也没有真实增长，纯炒作 | 不碰 |

**冯柳的陷阱警告（这也是一层灰色地带）：**
反身性股票赚钱最快，但反转也最惨——因为"金融幻觉"破裂时，反身性反向运作：股价跌→融资困难→无法扩张→业绩差→股价继续跌。

他知道这是泡沫，但他不回避泡沫——他是在泡沫的早期参与，在"人人都看到"的时候退出。

**这和Marks形成了一个有趣的对比：**
- Marks：识别泡沫，远离（防御优先）
- 冯柳：识别泡沫，参与早期，在泡沫破裂前退出

两个人的方法都有道理——取决于你的执行能力。

### 矛盾4：赔率优先 vs. 在不确定时如何行动

冯柳体系的核心是"赔率优先"——但赔率高低取决于你对"最坏情况"的判断。如果你判断错了呢？

**冯柳的解决方案（隐含在他的分散持仓里）：**
他不是在"判断准确→重仓"——他是在"判断不确定→分散→让市场帮他筛选"。

> "我会与很多股票建立连接，反复试错，反复开仓，通过增减来感受自己的内心。"

**这和量化的根本冲突：**
量化策略要求明确的入场/出场规则。冯柳的"反复开仓、体会内心"——这没法写进Python。

但可以翻译成：
```python
# 冯柳式渐进建仓（可量化版本）
phase_1_scout = allocate(1%, to=all_signals_above_threshold)
wait(N_days)
phase_2_add = allocate(3%, to=signals_with_positive_feedback)
wait(N_days)
phase_3_concentrate = allocate(10%, to=signals_where_odds_and_probability_aligned)
```

"正面反馈"和"赔率概率统一"——这两个条件仍然需要人类判断，但框架是可量化的。
