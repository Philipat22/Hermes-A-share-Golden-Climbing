# 洪灏 思维系统 v3：知道、不知道、在之间怎么动

## 首先回答一个根本问题：洪灏到底信什么？

不是五个模型。是一个核心矛盾，他自己活在这个矛盾里：

> 他把书名叫**《预测》**，但在几乎每一次采访里都会说**"我不知道"**。

这不是虚伪。这是他思维系统的两个支点：

- **支点A**："存在可识别的统计规律"（850天周期、息差相关、流动性传导）→ 他书名《预测》的底气来源
- **支点B**："具体时点和幅度不可知"（"我也不知道"、"下半年或更远"）→ 他区别于99%分析师的诚实

**关键在于：他不是在两个支点之间摇摆。他在两个支点之间建立了行动框架。**

这个"在知道和不知道之间如何行动"——才是他真正的思维系统。v2把五个模型并列讲，完全丢失了这个结构。

## 第一层：他"知道"什么（统计规律，不是因果定律）

### 1.1 中美息差是A股最单一、最强力的定价锚

**来源**：2024.7 专访原话
> "如果我们将沪深300指数的走势与中美息差的走势进行对比，两者之间的相关性基本上高达90%以上……试想，相关性高达百分之九十几，两条线的走势几乎是一模一样的。我有一张图被市场广泛传播。"

**为什么他敢说90%+：**
- 逻辑链清晰：息差 → 资本流动方向 → 美元强弱 → 人民币压力 → 央行降息空间 → A股估值
- 可验证：任何人在Bloomberg上都能拉出来验证
- 这条他最有信心，因为他依赖的是公开数据+简单计算，不需要什么深度研究

**但他同时知道这个规律不是永恒的：**
- "充分条件是美联储降息，必要条件是自身强"
- 如果中国自身经济强劲，即使息差不收窄，A股也能涨（只是历史上这种情况少了）

### 1.2 3.5年（850交易日）底部周期是统计规律

**来源**：2020年《预测》书 + 多年公开演讲

这个规律在一手访谈里没有详细展开数学细节。但从他的多次描述中可以推断：
- 不是精确到天的物理定律 → "具体的时间点难以确定……我也希望是下半年，但我不知道"
- 底部比顶部规律性强 → 他主要用这个判断"什么时候接近底部"，不主张用这个预测顶部
- 是**后验统计**不是**先验模型** → 他先发现了这个规律，再试图解释原因（可能是基钦周期+中国信用周期叠加）

**五个历史底部的验证**：
```
2005.06 → +3.5年 → 2008.10  ✓
2008.10 → +3.5年 → 2012.12  ✓
2012.12 → +3.5年 → 2016.01  ✓ (~1月延迟)
2016.01 → +3.5年 → 2019.01  ✓
2019.01 → +3.5年 → 2022.10  ✓
2022.10 → +3.5年 → 2026.04-06（我们可能正在穿过这个窗口）
```

**但他提醒自己：统计规律可能会破。** 如果AI改变了生产率曲线，3.5年可能会变。

### 1.3 流动性的短期决定力大于基本面

**来源**：2025.7 对话原话
> "如果基本面增速在放缓，是否对于我们的股票市场就不好了？我觉得短期来说，股票市场和基本面没有特别强的关系……基本面不好的话，股市照样涨，只要你的流动性能够放出来就可以了。"

这个观点很关键，因为它在专业投资者中**争议很大**。价值投资者会说"短期是投票机，长期是称重机"。洪灏没有否认长期，他的原话是"短期"。

**他的隐含定义**："短期"在他框架里大概是1-3年。对于大多数投资者来说，这已经够长了。

## 第二层：他"不知道"什么（且公开承认，这是他的稀有特质）

### 2.1 他公开承认的"不知道"

从两篇一手专访中可以统计他对"不知道"类回答的使用：

- "具体的时间点难以确定"（2024.7）
- "我也希望是下半年，但我不知道"（2024.7）
- "新高到多少我不知道，我也不想乱拍脑袋拍出来"（2025.7）
- "你怎么知道22000就是底？……你又怎么知道25000是顶？我觉得都是拍脑袋拍出来的数字"（2025.7）

**他的模式：** 当被问到点位、时点、具体催化剂时，他退到"我不知道"。当被问到方向、驱动力、环境特征时，他给清晰的回答。

**这不是谦虚，是他的认识论：** 方向可以判断，时点不可判断。统计规律能给"区域感"，但不能给精确日期。

### 2.2 他的认识论（推断，训练数据综合）

洪灏的思维底座可以用三句话概括：

1. **"可识别的是模式，不可识别的是时点"** — 这是他把书名《预测》和口头禅"我不知道"统一起来的逻辑
2. **"低预期比聪明预测更有用"** — 他反复强调"预期已经很低了"、"很容易突破预期"，这是他真正的alpha来源：不是准确预测未来，是识别市场已经price in了过多悲观
3. **"能被预见的都不是风险"** — 真正的风险是尾部事件，不可能被提前预见。所以风控不是"预测风险"，是"确保你不会死在尾部事件上"

## 第三层：在"知道"和"不知道"之间，他怎么行动？

这是v2完全没触及的核心层——他的实际操作哲学。

### 3.1 他不在左侧重仓，他在左侧观察+右侧跟进

**来源**：2025.7 对话原话
> "在炒作交易的时候，通常我不会仅仅因为一个股票跌而买，我会因为一个股票涨而买某个股票。因为跌的时候只有输家才摊平亏损……一个股票它跑输这个市场，是有原因的。虽然你当时可能并不知道是什么，可能事后几个月后，你才能意识到。"

**他的行动框架（从原话中提炼）：**

```
他"知道"的层：统计规律说底部可能在某个区域
   ↓
行动：不在这里重仓抄底
   ↓
他等待：统计规律被市场行为确认（低点开始抬高、成交量开始回升、息差开始收窄）
   ↓
行动：信号确认后才加仓
   ↓
他的哲学："信号比预测有用"
```

**这和2024年4-5月他的行为一致：**
- 2024年初A股在2600点时，他说"我相信这是今年的一个最低点"（基于统计规律），但他没有喊"现在满仓"
- 到了2024年4-5月，息差预期变化+成交量回升+低点上移，A股从2600涨到3100，他说"一波就上涨了"（信号确认了）
- 他没有在2600点满仓，也没有在3100点追高——他在确认过程中加仓

### 3.2 他靠"低预期 + 等确认"赚确定性，不靠"预测精准"赚暴利

这是洪灏和大多数"神棍分析师"的本质区别：

| | 神棍分析师 | 洪灏 |
|---|---|---|
| 怎么获取关注 | "我预测明天涨100点" | "统计规律说这里是底部区域" |
| 怎么做预测 | 单点预测（X月X日到X点） | 情景树（方向+概率） |
| 错了怎么办 | 不提 | "我不知道具体时点"已经提前打了疫苗 |
| Alpha来源 | 假装能预测不可预测的事 | 识别市场定价了过多悲观 |
| 最大利益点 | 短期暴利 | 长期不败 |

**他的真实alpha不是"判断对方向"。方向判断人人会，错一次就够了。他的alpha是：在悲观已经被充分定价时敢于入场，在叙事逻辑清晰时敢于持有，在趋势反转信号出现时敢于离场。**

### 3.3 他如何判断"悲观已经被充分定价"（推断）

从两篇专访中可以提炼他的判断框架：

```
信号1：预期已经极低
  → 国际货币基金组织和世界银行都上调了中国经济预期 → 之前的预期太低了
  → "在这种情况下，任何超出预期的表现都相对容易实现"

信号2：全球配置已经极端低配
  → 中国GDP占全球~20%，但在全球指数中权重是个位数
  → "如果我是指数基金主动型管理者……必须寻找并合理配置，包括中国市场在内的被低估的市场"

信号3：估值已在历史极端低分位
  → PE历史低分位结合破净率攀升
  → 但不以估值便宜为唯一买入理由——他2025.7说"估值可以更便宜"

信号4：趋势开始变化（最关键！）
  → "低点不断抬高说明趋势发生了一个改变"
  → 这是从"可能底部"到"确认底部"的信号转换
```

只有当≥3个信号同时出现，他才从"观察"切换到"行动"模式。

## 四、他的六个核心矛盾（v2只提到了1个）

### 矛盾1：书名《预测》vs 口头禅"我不知道"
**他的调和**：预测的是"方向+概率"，不预测的是"时点+点位"。两件事在别人那里被混为一谈，在他那里是分开的。

### 矛盾2：统计规律的信徒 vs 统计规律的怀疑者
他相信850天周期，但也在2024年强调AI革命"才刚刚开始"，暗示旧的周期可能被打破。他自己也不确定。

### 矛盾3：动量交易 vs 周期投资
他对交易层面说"跌的不买、涨的才买"（动量思维），但在宏观层面说"周期底部应该超配"（均值回归思维）。这两个在同一个大脑里共存——交易用动量，战略用周期。

### 矛盾4：中国结构乐观 vs 中国周期悲观
他在2024-2025的采访中，同时表达了：
- "中国市场估值便宜、全球超低配、均值回归是必然的"（长期乐观）
- "房地产不企稳周期难以修复、去产能极其困难、经济放缓大概率"（中期悲观）
- 这两个在时间尺度上是兼容的——中期苦、长期好——但情绪上是矛盾的

### 矛盾5：宏观正确 vs 个股无知
他在宏观层面非常自信（周期、息差、流动性），但在个股层面不过度深入（他很少讲具体股票的基本面）。他赚的是"宏观定价错误"的钱，不是"个股超预期"的钱。

### 矛盾6：离开机构、自己管钱（skin in the game）
2025年他在华福国际只待了2个月就离开，去莲华资产自己管钱。这是Taleb所说的"skin in the game"——当他开始用自己的钱（和客户的钱）验证自己20年的框架时，他承受了最大的压力。

## 五、当洪灏遇到一个新问题时，他怎么想？（模拟）

**输入**：A股现在能买吗？

**他的思维链（不是结论，是过程）：**

```
Step 1 — 中美息差在哪？
  "先看中美息差。如果还在-200bp以上且没有收窄迹象，谈什么都是空的。"

Step 2 — 统计周期在哪？
  "2022年10月+3.5年≈2026年4-6月。我们在周期窗口附近。但窗口是区域不是点。"

Step 3 — 市场预期在哪？
  "现在市场在担心什么？去产能？关税？房地产？——这些都被说了多久了，可能已经被price in了。市场没在想什么？——也许是AI的实际盈利超预期，也许是政策突然转向。"

Step 4 — 信号确认了吗？
  "低点在抬高吗？成交量从冰点恢复了吗？北向资金在回来吗？——如果没有，我就再等。如果有了，我再加。"

Step 5 — 结论
  "我会说现在是值得关注的区域。但我不知道具体哪一天是最佳买入点。如果有仓位拿住，如果没有仓位可以慢慢建。不要ALL IN——因为'能预见的都不是风险'，真正的风险我还没看到。"
```

**对比：普通分析师会在Step 2就给结论**（"3.5年周期到了，赶紧买"），洪灏会走到Step 5还留一手。

## 六、洪灏框架的实战集成

### 对他最擅长的场景

| 场景 | 他的信号 | 行动建议 |
|------|----------|----------|
| 息差从-250bp收窄到-150bp | 核心正面信号 | 开始加仓 |
| 低点连续3月抬高 | 趋势确认 | 持有+逐步加仓 |
| 2026年4-6月窗口 | 周期底部区域 | 关注但不盲动 |
| 市场预期极度悲观 | 负面已price in | 反向思考机会 |

### 对他的盲区

1. **在极端恐慌时不敢抄底**：2022.10的港股15000点，按他的动量思维应该等确认。但如果等到2023.1确认，错过了2000点。
2. **在AI时代的周期有效性**：他的3.5年周期是基于2005-2022的数据。2023年之后的AI革命是否改变了周期的节奏？
3. **对个股的指导有限**：他判断宏观方向很强，但"买什么"不是他的专长。
4. **离开机构后的track record未验证**：他在交银/思睿做研究，在莲华做投资。研究和投资是两回事。
