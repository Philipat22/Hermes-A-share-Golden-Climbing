# 段永平 A股适配层: "不懂不做，等好球"

## 定位

段永平在体系里的角色最特别——**他不参与安检门。他是你的选股师傅。**

其他六位大师都在说"什么时候买/该不该买/买多少"——段永平说"你买的到底是什么"。

他是A股唯一一个用"买公司"思维做投资、而且公开验证过（网易100倍、苹果、茅台、腾讯）的人。不是理论家，是实践者。

---

## 一、六大心智模型 —— 几乎不用翻译，A股原生

### 1. 商业模式是过滤器

**段永平原话**: "买股票就是买公司，买公司就是买其未来现金流折现。"

**不是**看K线、不是看DD、不是看趋势——是看这个公司怎么赚钱，这个赚钱方式10年后还在不在。

**A股例子**: 
- 茅台: 商业模式极其简单——涨价就行。护城河=品牌+渠道+不可复制。段永平最爱的类型。
- AI概念股: 你不真的懂它的商业模式——你懂的是"大家觉得它会涨"。这不是商业模式，这是共识。段永平不买。

**对你的策略**: 你的DD信号里有多少只票你真的能说清楚它的商业模式？如果说不清楚——段永平会说你是在"炒股"，不是"买公司"。

---

### 2. Right Business, Right People, Right Price

**段永平原话**: 三者的重要性是递减的——生意模式最重要，人其次，价格最后。

**A股翻译**: 大多数人倒着来——先看价格（便宜就买），再看人（管理层行不行），最后才想生意模式。段永平说这是死路。

**可执行规则**: 任何买入决策，按这个顺序想：
1. 这个生意10年后还在吗？怎么赚钱？
2. 管理层是在为股东创造价值还是在为自己？
3. 现在的价格合理吗？

如果第一题就答不上来——后面不用想了。

---

### 3. 能力圈

**段永平原话**: "我懂的生意很少。"

这句话从一个赚了几百倍的人嘴里说出来，分量完全不同。

**A股翻译**: 段永平懂多少？苹果（消费电子+生态）、茅台（品牌消费品）、腾讯（社交+游戏+支付）、网易（他早期深研的）。就这几个。

你懂的生意有多少？黄金坑的DD信号覆盖了多少你完全不懂的行业？如果答案是"大部分"——段永平会说你做得太多了。

---

### 4. 本分

**段永平原话**: 做对的事，把事情做对。

这个概念在A股非常稀缺——因为A股充满了"不对的事"（炒作、内幕、收割）。段永平说的本分是：承认自己只是个普通投资者，不做能力圈外的事，不被市场的噪音带偏。

**对你的策略**: 本分 = 不在牛末满仓AI概念股、不在恐慌时清仓黄金坑信号、不为"别人赚了"而改变自己的框架。

---

### 5. 敢为天下后

**段永平原话**: "我们进去的时候，这个市场就要是我们的了。"不是不做先驱——是不做第一个吃螃蟹的人。等市场验证了需求，再用更好的产品收割。

**A股翻译**: 段永平不追热点。AI概念涨了200%也不追——因为他看不懂。等他真的看懂了（如果有一天他看懂了），他会等回调再买。

**对你的策略**: 你不应该在AI概念股启动时追涨（冯柳和洪灏也会反对）。但你应该在AI概念股深度回调（DD≥40%）+商业模式清晰可见时考虑。

---

### 6. 未来现金流折现

**段永平原话**: 所有的估值最终都回到"这个公司未来能赚多少钱，折到现在值多少"。

**A股翻译**: 段永平不是在算DCF模型（他明确说过不搞复杂的数学）。他是用"常识"判断——这个生意10年后大概率还在赚钱吗？大概能赚多少？现在价格低于这个数吗？

**可执行规则**: 不要求你算精确的DCF。要求你回答一个简单问题：这只票现在的价格，按它现在的赚钱能力，5年能回本吗？如果不能——你为什么买它？

## 二、段永平在体系里的位置

```
选股流程:
├─ 1. 冯柳: 三杀分类 → 是杀估值/杀逻辑吗？
├─ 2. 段永平: 商业模式过滤器 → 10年后这生意还在吗？
├─ 3. 安检门(四人): 市场状态允许吗？
└─ 4. Taleb: 仓位不会让我死吗？
```

段永平不是说"这个可以买"——他是说"这个我不懂，不买"或者"这个我看得懂，在合理价格上可以买"。

**最强大的不是他的yes，是他的no。**

## 三、安检门规则

段永平的规则不是代码——是**人工判断**。但可以量化成自检清单：

```python
def duan_check(signal):
    """段永平式选股自检 — 不是代码自动判断，是人要回答"""
    
    questions = [
        ("商业模式", "这个生意怎么赚钱？10年后还在吗？"),
        ("护城河", "别人为什么不能复制？"),
        ("管理层", "管理层在做对的事吗？"),
        ("能力圈", "我真的懂这个生意吗？（不需要是专家，但要懂基本逻辑）"),
        ("价格", "现在价格合理吗？（不需要精确估值，但大概判断贵不贵）"),
    ]
    
    # 如果任何一题答不上来 → 不买
    for category, question in questions:
        answer = signal.get(f'duan_{category}', '')
        if len(answer) < 20:  # 少于20字说明没认真想
            return False, f"段永平{category}检查: '{question}' → 无答案 → 不买"
    
    return True, "段永平通过"
```

**这条规则不放在safety_gate.py的批量检查里——它是你在下单前手写的。**

## 四、段永平 vs 冯柳（直接冲突，必须调和）

| 问题 | 段永平 | 冯柳 | 调和 |
|------|--------|------|------|
| 选股方式 | 深度研究商业模式 | 弱者体系，不深度研究 | 段永平管"长期持有的票"，冯柳管"中短期反弹的票" |
| 持仓周期 | 3-10年 | 中线（数周到数月） | 你的黄金坑是中短线——更适合冯柳 |
| 买什么 | 看得懂的少数公司 | 赔率高的任意公司 | 段永平圈内的票可以重仓，圈外的票用冯柳方式小仓 |
| "不懂"怎么处理 | 不碰 | "低位证明无"即可 | 段永平更保守——冯柳更愿意在不确定中行动 |

**调和方案**: 
- 如果你持有一只票3年以上 → 用段永平框架
- 如果你持有一只票40-60天（黄金坑）→ 用冯柳框架+安检门
- 如果一只票DD≥30%但你完全不懂它的生意 → 冯柳说可以买，段永平说不可以 → **这个冲突本身就是在提醒你：仓位要小**
