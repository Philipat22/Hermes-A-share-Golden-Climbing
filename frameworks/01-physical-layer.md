# 物理层检查

- **来源**: Musk 第一性原理
- **触发时机**: 提出任何新策略/信号时（第一个跑的框架）
- **角色**: 判定策略是否服从市场的物理约束。不服从 → 直接毙，不需要后续验证。

## 输入
- 策略定义（干什么、什么时候干、持有多久）
- 市场物理约束列表（见下方常量）

## 市场物理约束（A股硬常量）
1. T+1：买入当天不能卖出
2. 涨跌停 ±10%（科创 ±20%）：极端行情无法执行
3. 散户占比 60%+：情绪驱动 > 价值驱动
4. 做空受限：只能做多赚钱，无法对称表达负面观点
5. 无日内回转：日内 alpha 不可实现

## 分析步骤

### 步骤 1：列约束
确认上述 5 条约束全部适用。（科创板策略需调整涨跌停幅度）

### 步骤 2：推导允许的策略类型
从约束推导：
- T+1 + 无做空 → 只能持有正向敞口 → 均值回归天然服从（低买高卖），动量天然不服从（无法做空对手方）
- 散户 60%+ → 价格偏离价值的幅度和频率高于成熟市场 → 均值回归机会更多
- 涨跌停 → 极端行情流动性消失 → 必须考虑无法平仓的尾部情景

### 步骤 3：判定当前策略
将策略归类到「允许域」或「禁止域」：

| 策略逻辑 | 判定 | 理由 |
|---------|------|------|
| 均值回归（超跌买入） | 允许 | T+1 不影响，做多即可，散户情绪制造偏离 |
| 趋势跟随（追涨） | 警告 | 做空受限使对手方缺失，追涨 = 接盘 |
| 动量策略 | 禁止 | 物理上不对称：只能追涨不能追跌 |
| 日内交易 | 禁止 | T+1 直接禁止 |
| 多空对冲 | 禁止 | 做空受限 |

## 输出
- **通过**: 策略在允许域内 → 进入对手方分析
- **警告**: 策略在灰色区域 → 需额外论证为什么物理约束不致命
- **拒绝**: 策略在禁止域内 → 不进入后续流程，直接毙

## 反例
- "牛市动量策略" → 物理层拒绝：做空受限 + 散户 60%+ → 动量天然不服从 A 股物理约束
- 验证：Layer 0 数据 — 动量中位 -2.06%，胜率 36.1%，逐年恶化 → 数据证实了物理层的推导
