# 对手方分析

- **来源**: 冯柳 "A股赚钱不靠研究公司，靠研究谁在亏钱"
- **触发时机**: 物理层通过后，每个信号触发时
- **角色**: 识别交易对手方 → 判断对手方是否在恐慌性卖出 → 确认对手方已离场

## 核心逻辑

A股是负和博弈（含交易成本）。每一笔盈利 = 对手方的亏损。所以要赚钱，必须确认：**对手方确实在亏钱卖出**。

## 输入
- 信号：哪个票、什么信号触发
- 市场状态：牛市/熊市/震荡

## 分析步骤

### 步骤 1：识别对手方类型

| 信号类型 | 对手方身份 | 亏损动机 |
|---------|-----------|---------|
| DD ≥ 30%（恐慌） | 散户 | 恐慌割肉 — 看到跌太多受不了 |
| DD ≥ 30%（牛市） | 主力 + 散户 | 主力已跑，散户接盘 — 不是恐慌是真烂 |
| 窄 DD（-20%~-30%） | 游资 | 止损线触发 — 纪律性割肉 |
| 连续跌停 | 杠杆资金 | 爆仓强平 — 被迫卖出 |

### 步骤 2：判断对手方是否已离场

三个确认信号（必须同时满足至少 2 个）：
1. **缩量到极致**: VR < 0.5x 历史均值（没人卖了）
2. **跌速放缓**: 最近 5 日跌幅 < 前 20 日日均跌幅（恐慌衰竭）
3. **DD 不再扩张**: DD 值近 3 日波动 < 2pp（抛压耗尽）

只满足 1 个 → 对手方可能还在 → 不进场。

### 步骤 3：确认"你接的不是飞刀"

关键区分：
- 熊市 DD≥30%：对手方 = 恐慌散户 → 他们在亏钱卖 → **可以接**
- 牛市 DD≥30%：对手方 = 先知先觉的主力 + 跟风散户 → 主力在出货 → **不能接**

数据支撑：Layer 0 — 熊市 DeepDD30 中位 +3.0%，牛市 -0.4%。同一信号，方向相反。

## 输出
- **对手方明确 + 已离场**: 信号有效 → 进入量化验证
- **对手方模糊**: 标记为"需人工判断" → 进入 Layer 4
- **对手方是主力**: 信号无效 → 放弃

## 反例
- "这只票跌了 40%，估值很便宜了" → 对手方分析：谁在卖？如果是主力在出货，"便宜"只是陷阱
