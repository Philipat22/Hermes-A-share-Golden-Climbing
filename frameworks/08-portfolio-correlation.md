# 组合相关

- **来源**: Dalio — 信号的独立性比信号的期望更重要。两个高度相关的正期望信号 = 在同一个因子上加倍下注
- **触发时机**: 持仓调整时（新增或替换）
- **角色**: 检查信号/持仓之间的相关性 → 发现隐藏的集中度风险 → 调整权重

## 核心逻辑

如果你持有 3 只票，直觉上是分散了。但如果 3 只票在同一个信号（如 DeepDD30）上高度触发，或者同属一个板块——本质上是一笔交易拆成了 3 份。你承担了 3 倍的下行风险，没有 3 倍的分散收益。

## 输入
- 当前持仓列表（票 + 仓位）
- 新增候选
- 信号重叠矩阵
- 板块/行业数据

## 分析步骤

### 步骤 1：信号源重叠检查

计算每个持仓的信号触发源：

| 持仓 | 触发信号 | 权重 |
|------|---------|------|
| 票A | DeepDD30 | 20% |
| 票B | DeepDD30 | 15% |
| 票C | DeepDD30 + 绿芽 | 10% |

如果 A、B、C 都源于 DeepDD30 → 信号源重叠 = 100%。这是同一个因子 × 3 倍杠杆，不是分散。

信号源重叠 > 50% → 警告。> 80% → 必须削减。

### 步骤 2：板块集中度检查

同一板块（按概念板块或申万行业）总权重：

```
板块 X: 票A(20%) + 票B(15%) = 35%  → 超标
板块 Y: 票C(10%)                  → 正常
```

单板块上限：30%。

### 步骤 3：历史收益相关性

计算持仓之间的历史收益相关系数矩阵：

```
       票A    票B    票C
票A   1.00   0.72   0.18
票B   0.72   1.00   0.05
票C   0.18   0.05   1.00
```

票 A 和票 B 相关系数 0.72 → 高度相关 → 两个选一个。

相关系数 > 0.6 → 警告。 > 0.8 → 必须削减。

### 步骤 4：综合风险调整

三种重叠（信号源 / 板块 / 相关系数）同时超标 → 加倍惩罚：

```
如果 信号源重叠 > 50% AND 板块 = 同一板块 AND 相关系数 > 0.6:
    建议: 只保留其中一只，或大幅降仓
```

## 输出
- **分散良好**: 信号源重叠 < 50%，板块 < 30%，相关系数 < 0.6
- **警告**: 1-2 项超标 → 标记风险，限制新增
- **必须调整**: 3 项同时超标 或 任意一项严重超标 → 减仓或替换

## 与仓位敞口的关系
仓位敞口管单笔下多少。组合相关管多笔之间是否真的独立。两个一起用 — 凯利告诉你 14%，组合相关告诉你"但如果 3 只票都一样，14% 要降到 5%"。

## 反例
- 恐慌扫描器 + 黄金坑扫描器：底层都是 DD，如果信号重叠 > 60% → 不是两个独立策略，是一个策略的两个包装。组合相关会捕获这个盲区。
