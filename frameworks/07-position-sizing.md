# 仓位敞口

- **来源**: 葛卫东 — 从分布推导仓位，不凭感觉下注
- **触发时机**: 信号通过安检门后，每一笔具体交易下单前
- **角色**: 计算这一笔该下多少，不是"要不要下"

## 核心逻辑

信号的历史分布定义了：赢的概率、赢的幅度、输的幅度、最坏情况。仓位不是独立于信号的——它从信号分布中推导出来。

## 输入
- 信号收益分布（来自 Layer 0）
- 账户总资产
- 当前持仓（避免集中度风险）

## 分析步骤

### 步骤 1：凯利公式（理论仓位）

```
f* = (win_rate × avg_win - lose_rate × |avg_loss|) / (avg_win × |avg_loss|)
```

以 DeepDD30 为例：
- win_rate = 57.4%, avg_win ≈ +18%, lose_rate = 42.6%, avg_loss ≈ -15%
- f* ≈ (0.574×0.18 - 0.426×0.15) / (0.18×0.15) ≈ 14.5%

理论仓位约 14-15%。

### 步骤 2：尾部惩罚

凯利假设连续分布。但真实世界有左尾：
- 左尾 5%: -24.3%
- 左尾 1%: 可能在 -40% 以下

按左尾 5% 计算尾部惩罚：
```
tail_penalty = |left_tail_5| / |avg_loss| = 24.3% / 15% ≈ 1.62
adjusted_f = f* / tail_penalty = 14.5% / 1.62 ≈ 8.9%
```

尾部惩罚后仓位约 8-9%。

### 步骤 3：单票上限

硬约束：单票 ≤ 账户总资产的 25%。这是绝对上限，不因凯利值高而突破。

### 步骤 4：总仓位上限

硬约束：总仓位 ≤ 账户总资产的 80%。永远留 20% 现金应对黑天鹅和追加保证金。

### 步骤 5：同批次同板块约束

同一批次、同一板块 ≤ 1 只票。防止在同一个因子上加倍下注。

## 输出
```
建议仓位: X% (凯利 X% → 尾部惩罚后 X% → 单票上限 min(X%, 25%))
总仓位检查: 当前 Y%，剩余空间 Z%
板块检查: 当前板块已有 N 只，是否允许追加
```

## 约束
- 单票 25% 绝对上限不可突破
- 总仓位 80% 绝对上限不可突破
- 同板块 ≤ 1 只
- 如果分布样本 < 200，凯利计算不可靠 → 使用固定仓位 5%

## 反例
- ¥40K 账户，14.5% 单票 ≈ ¥5,800。左尾 5% 分位 -24.3% → 单笔极端亏损 ¥1,410。能扛吗？如果扛不了 3 次连续极端亏损 → 仓位还应再降
