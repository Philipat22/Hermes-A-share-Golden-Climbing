# 反身性判断

- **来源**: Soros 反身性理论 — 分布不是固定的，市场状态会改变信号行为
- **触发时机**: 信号通过对手方检查后，在量化验证的同时运行
- **角色**: 诊断当前市场状态 → 查信号在该状态下的历史表现 → 判断当前是否在衰减区

## 核心逻辑

一个信号的历史中位 +3.0%，不等于"现在触发也能赚 3.0%"。分布会随市场状态漂移。反身性框架的目的是：**检测当前状态是不是信号的衰减区**。

## 输入
- 信号历史分布（来自 Layer 0）
- 当前市场状态指标（见下方）
- 滚动审计数据

## 市场状态诊断指标（4 个硬指标）

| 指标 | 计算 | 含义 |
|------|------|------|
| 总市值/M2 | A股总市值 ÷ M2 货币供应 | >0.8 = 泡沫区，<0.4 = 低估区 |
| 融资余额环比加速度 | (本月融资 - 上月融资) ÷ 上月融资 | 加速上升 = 杠杆过热，加速下降 = 去杠杆 |
| 换手率 Z-score | (当前换手率 - 2年均值) ÷ 2年标准差 | >2 = 过热，<-1 = 冰点 |
| 政策信号密度 | 近30天重大政策公告数 | 高密度 = 政策市，可能扭曲信号 |

## 分析步骤

### 步骤 1：状态分类
根据 4 个指标将当前市场归类：
- **恐慌区**: 换手率 Z < -1 + 融资余额加速下降 → 信号最强区
- **正常区**: 所有指标在 ±1 标准差内 → 信号正常
- **过热区**: 换手率 Z > 2 或 总市值/M2 > 0.8 → 信号衰减
- **政策扭曲区**: 政策信号密度 > 阈值 → 信号可能被干扰

### 步骤 2：条件分布查询
在 Layer 0 中查询：**历史上该信号在类似市场状态下的表现**

```
信号 DeepDD30 在 恐慌区: 中位 +5.8%, 胜率 62%
信号 DeepDD30 在 正常区: 中位 +2.1%, 胜率 54%
信号 DeepDD30 在 过热区: 中位 -1.2%, 胜率 42%
```

### 步骤 3：衰减检测
滚动审计：近 3 个月信号中位 vs 历史中位
- 偏离 > 2pp → 标记"衰减" → 信号降权或暂停
- 偏离 1-2pp → 标记"观察" → 正常使用但监控
- 偏离 < 1pp → 正常

## 输出
- **恐慌区**: 信号加权重（预期收益高于历史中位）
- **正常区**: 信号正常权重
- **过热/政策扭曲/衰减**: 信号降权或跳过

## 关键约束
反身性判断**只能降权不能升权**超过历史最优。它在分布外围加一层安全边际，不是在"择时"。

## 反例
- 2023 年 DeepDD30 中位 -2.8%：如果反身性框架在 2023 年运行，会在 Q2 检测到连续 3 个月偏离 > 2pp → 标记衰减 → 暂停信号 → 避免当年损失
