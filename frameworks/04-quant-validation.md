# 量化验证

- **来源**: Simons 量化思维 — 数据驱动，不凭直觉
- **触发时机**: 任何信号或策略想法提出后
- **角色**: 把"我觉得"变成"数据说"——定义可检验假设 → 跑全量数据 → 报告效应量和置信区间

## 核心原则

1. **全量 > 采样**: 5766 只票，不是 300 只。字典序前 3000 只 ≠ 全市场。
2. **效应量 > 显著性**: p < 0.01 但中位差只有 0.5pp → 统计显著但经济无意义
3. **前向验证 > 全样本**: 全样本中位 +3.0% 可能来自过拟合，前向验证 4 窗口才能暴露
4. **不美化数据**: 跑输了就说跑输了

## 输入
- 信号定义（精确的触发条件）
- 数据范围（时间、股票池）

## 分析步骤

### 步骤 1：定义零假设
H₀: 信号触发后的收益分布 = 任意一天随机买入持有 N 天的收益分布

零假设通过 Bootstrap 10,000 次构造：从 CSI300 日收益中随机抽取 N 天滚动收益。

### 步骤 2：全量扫描
在全部可用股票 × 全部交易日上运行信号定义。记录每次触发的：
- 前向收益（40 天）
- 触发日期
- 市场状态（牛/熊）

### 步骤 3：计算效应量

| 指标 | 含义 | 验收阈值 |
|------|------|---------|
| 中位差 | 信号中位 - 零假设中位 | > 2pp |
| 胜率差 | 信号胜率 - 零假设胜率 | > 5pp |
| KS p-value | 信号分布 vs 零假设分布是否同分布 | < 0.01 |
| 盈亏比 | avg_win / |avg_loss| | > 1.2 |
| 偏度 | 分布不对称程度 | < 0.5（真实世界罕见正偏） |

### 步骤 4：前向验证
4 轮滚动窗口：训练到 T-1 → 验证 T 年 → 记录中位。4 轮中位范围（max-min）< ±3pp 才算稳定。

### 步骤 5：逐年拆解
逐年中位 — 检查是否有单一年份异常。2023 年 DeepDD30 中位 -2.8% 就是逐年拆解发现的。

### 步骤 6：Bootstrap 鲁棒性
对信号分布做 10,000 次 Bootstrap → 计算 VaR 置信区间宽度。宽度 > 3pp → 分布估计不可靠。

## 输出
一张效应量表，包含所有指标 + 通过/未通过标记。不允许"接近通过"——阈值是硬的。

## 约束
- 不优化参数。量化验证只报告当前定义下的分布，不说"阈值改成 XX 更好"
- 不解释原因。只报告数据，解释留给其他框架

## 反例
- 黄金坑初版：缓存被污染 → 信号中位被夸大 +21% → 前向验证崩溃 → 被证伪
- 教训：量化验证的每一步（数据源、计算逻辑、交叉验证）都必须可复现
