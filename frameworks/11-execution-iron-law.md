# 交易员铁律

- **来源**: 交易员 — 数据说了不，你听不听
- **触发时机**: 所有框架分析完成后，最终按下"下单"按钮之前。以及持仓期间每一天。
- **角色**: 执行纪律。最好的分析如果不执行，等于没有。最坏的分析如果执行了，承担后果。

## 核心逻辑

分析可以复杂。执行必须简单。11 个框架可以给你 11 页报告——但下单那一刻，你只需要回答一个问题：**数据让我下单，还是数据让我停？**

交易员铁律不分析数据。它强制执行数据已给出的结论。

## 铁律清单

### 铁律 1：安检门不过 = 不下单
不管其他框架说什么。安检门有一条不通过，不下单。
- "再看看" = 违反铁律
- "这次不一样" = 违反铁律
- "仓位小没关系" = 违反铁律

### 铁律 2：硬止损触发 = 无条件执行
尾部风险框架定义的硬止损：
- 单日回撤 > 5%: 无条件减半仓
- 单笔亏损 > 15%: 无条件清仓
- 单月回撤 > 10%: 暂停交易 1 周

不允许：
- "已经跌了这么多，再等等反弹" — 违反铁律
- "基本面没变" — 违反铁律。硬止损不管基本面。
- "止损线太紧了" — 应该在交易前调整规则，不能在触发时临时改

### 铁律 3：精算合成黄灯必降仓
精算合成输出"黄灯"→ 仓位从凯利计算值再降 30-50%。不因"看着机会好"而加回来。

### 铁律 4：不追信号热
信号触发频率突然翻倍（如每天 5 次变成每天 20 次）→ 暂停 3 天，检查是否数据问题或市场异常。

### 铁律 5：不替代其他框架
交易员铁律不替代任何分析框架。它做的是：当分析结论清楚了，确保手执行了。

### 铁律 6：复盘 ≠ 改规则
亏损 → 复盘 → 如果发现框架漏了什么 → 修改框架。但修改的是**未来的规则**，不是**当前的止损**。当前这笔按旧规则执行到底。

## 红线（不可触碰）
- 手动关闭硬止损
- "这次例外"
- 连续 2 次黄灯仍全仓
- 单季度违反铁律 > 2 次（说明执行系统崩溃，需要全面暂停）

## 输出
```
最终执行: [下单 / 不下单 / 降仓下单]
仓位: X%
硬止损线: -Y%
复盘触发条件: (如果触发，何时复盘)
```

## 与其他框架的关系
交易员铁律是最后一个跑的框架。它不分析、不计算、不判断。它把前面所有的分析结果翻译成一个动作：**做，还是不做。**

这是整个系统里唯一不能自动化的框架——因为 AI 可以说"执行"，但按下按钮的是人。

## 反例
- 动量策略被安检门毙了（中位 -2.06%）。如果交易员说"但牛市里不一样"→ 违反铁律 1 → 被阻止
- DeepDD30 触发，下了单。当天跌了 6%。硬止损（单日 > 5%）触发。交易员说"等等，明天可能反弹"→ 违反铁律 2 → 必须减仓
